How it works

  • Receive an uploaded image
  • Generate a compact signature from the file content
  • Compare it with stored missing-person records
  • Return the closest match with a confidence score

Technology stack

  • Node.js + Express for the web app
  • HTML, CSS, and JavaScript for the interface
  • Computer vision concepts for future expansion
  • MySQL and deep-learning workflows planned for production
